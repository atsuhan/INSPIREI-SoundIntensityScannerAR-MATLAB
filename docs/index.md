# Documentation Index

タスクに関係する文書だけ読むこと。全ファイルを一括で読まない。

- 現在の作業選択: `roadmap/MILESTONES.md`
- 共通ルール: `rules/common.md`
- プロジェクト固有ルール: `rules/project.md`
- 検証方法: `quality.md`（存在する場合）
- アーキテクチャ: `architecture.md`（設計変更時・存在する場合）
- 大規模な設計: `specs/`
- 外部調査: `research/`
- 長期的な技術判断: `decisions/`
- 完了済み履歴: `roadmap/archive/`
- 環境構築の詳細: `setup.md`（READMEに収まらない場合）

文書が存在しない場合、必要性が明確になるまで新規作成しない。
